# CHIP-8 test ROMs

The ROMs in this folder come from the
[CHIP-8 test suite](https://github.com/Timendus/chip8-test-suite) by Timendus
(`bin/*.ch8`, unmodified).

- Repository license: GPL-3.0 (see https://github.com/Timendus/chip8-test-suite/blob/main/LICENSE).
- `3-corax+.ch8` is an adaptation of the test ROM by corax89
  (https://github.com/corax89/chip8-test-rom); its source file header states the MIT license
  (c) 2019 corax89, 2023-2024 Timendus.

GPL-3.0 is compatible with this project's AGPL-3.0-only code. These ROMs keep their own licenses.

| File               | Test                                    |
| ------------------ | --------------------------------------- |
| `1-chip8-logo.ch8` | CHIP-8 logo (basic drawing)             |
| `2-ibm-logo.ch8`   | IBM logo (basic drawing and jumps)      |
| `3-corax+.ch8`     | Opcode test                             |
| `4-flags.ch8`      | VF flag behavior                        |
| `5-quirks.ch8`     | Quirks (COSMAC VIP / SCHIP differences) |
| `6-keypad.ch8`     | Keypad input                            |
